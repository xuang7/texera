### Input Properties

| Property | Requirement | Type | Default | Description |
|----------|-------------|------|---------|-------------|
| Regression | ✓ | Boolean | false | Choose to solve a regression task |
| ↳ Scorer Functions |  | List<Accuracy, Precision Score, Recall Score,<br>F1 Score> | - | Select classification tasks metrics. Hidden when<br>`Regression` is `true` |
| ↳ Scorer Functions |  | List<MSE, RMSE, MAE, R2> | - | Select regression tasks metrics. Hidden when<br>`Regression` is `false` |
| Actual Value | ✓ | String | - | Specify the label attribute |
| Predicted Value | ✓ | String | - | Specify the attribute generated by the model |
