Interactive data visualization operators.

| Category | Operators | Use Case |
|----------|-----------|----------|
| [Basic](basic/) | Bar, Line, Pie, Scatter, Bubble, etc. | Quick comparisons, trends, and composition for everyday reporting |
| [Statistical](statistical/) | Box/Violin, Histogram, Scatter Matrix | Distribution, outliers, and multivariate exploration |
| [Scientific](scientific/) | Heatmap, Contour, Network Graph, Dendrogram | Continuous fields, structures, and spatial/graph data |
| [Financial](financial/) | Bullet, Candlestick, Funnel, Waterfall | Time-series price action and range/interval analysis |
| [Media](media/) | HTML, Image, URL, Word Cloud | Embed or render non-tabular media/HTML artifacts |
| [Advanced](advanced/) | 3D Scatter | Higher-dimensional or specialized interactive plots |
