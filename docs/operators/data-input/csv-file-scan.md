## CSV File Scan

### Overview

The **CSV File Scan** operator reads CSV files and outputs structured records. Supports various delimiters and encodings.

### Properties

#### Input

| Property | Required | Type | Default | Description |
|----------|----------|------|---------|-------------|
| **File** | ✓ | String (URI) | - | The CSV file to read |
| **File Encoding** | ✓ | FileDecodingMethod | `UTF_8` | Character encoding |
| **Limit** |  | Integer | (all) | Max rows to output |
| **Offset** |  | Integer | 0 | Rows to skip before output |
| **Delimiter** |  | String | `,` | Field separator (`,`, `\t`, `;`, etc.) |
| **Header** |  | Boolean | ✓ | First row contains column names |

#### Output

| Output | Type | Description |
| --- | --- | --- |
| **Output Port 1** | Table (rows) | A structured dataset parsed from the CSV file. Column names and types are inferred from the file contents. |


##### Autogenerated version

| Property | Required | Type | Default | Description |
| --- | --- | --- | --- | --- |
| INFER READ LIMIT | N | int | - |  |
| File Encoding | Y | FileDecodingMethod | - | decoding charset to use on input |
| File | Y | Option | - |  |
| File Type Name | N | Option | - |  |
| Limit | N | Option | - | max output count |
| Offset | N | Option | - | starting point of output |
| Delimiter | N | Option | None | delimiter to separate each line into fields |
| Header | N | Boolean | true | whether the CSV file contains a header line |

### Tips

{{< alert color="warning" title="Common Issues" >}}
- **Garbled characters** — Try changing File Encoding
- **All data in one column** — Check your Delimiter setting
- **Missing first row** — Toggle Header checkbox
