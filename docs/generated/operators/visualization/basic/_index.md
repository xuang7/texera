Common chart types for everyday data visualization.

| Operator                                      | Description |
|-----------------------------------------------|-------------|
| [Bar Chart](bar-chart/)                       | Compare values across categories |
| [Bubble Chart](bubble-chart/)                 | Scatter plot with sized points |
| [Dot Plot](dot-plot/)                         | Compare values with dots |
| [Dumbbell Plot](#dumbbell-plot)               | Show change between two points |
| [Figure Factory Table](#figure-factory-table) | Styled data tables |
| [Filled Area Plot](#filled-area-plot)         | Area chart for cumulative data |
| [Gantt Chart](#gantt-chart)                   | Project timeline visualization |
| [Hierarchy Chart](#hierarchy-chart)           | Treemap for hierarchical data |
| [Icicle Chart](#icicle-chart)                 | Hierarchical data as nested rectangles |
| [Line Chart](#line-chart)                     | Show trends over time |
| [Pie Chart](#pie-chart)                       | Display proportions of a whole |
| [Scatter Plot](#scatter-plot)                 | Visualize relationships between variables |
| [Sankey Diagram](#sankey-diagram)             | Flow between categories |
| [Tables Chart](#tables-chart)                 | Display tabular summaries |
| [Ternary Plot](#ternary-plot)                 | Three-variable composition |
